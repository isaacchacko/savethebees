library

Commits to content/cool.json in your site repo. Needs a fine-grained token scoped to that one repo with Contents: Read and write.

Private entries are encrypted with this before they are committed, and it is what you type on the site to see them. Make it long: the encrypted file is in a public repo, so anyone can try guesses against it offline. Changing it here re-encrypts the private entries under the new one in a single commit. The site has no copy of it, so there is nothing else to update.
